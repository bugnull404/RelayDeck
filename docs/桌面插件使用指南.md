# RelayDeck Desktop 使用指南

RelayDeck Desktop 是 Windows 上的 Codex 插件。它在 Codex 内提供 **RelayDeck 设置**，并运行一个仅绑定本机回环地址的 HTTPS 网关，让已授权的手机访问 Codex 桌面会话。

## 系统要求

- Windows 10/11 x64
- Codex 桌面端
- Node.js 24（发布包已内置）
- 首次安装可联网下载固定版本的 EasyTier 原生依赖

## 安装

1. 下载并完整解压 `relaydeck-desktop-<版本>.zip` 到固定目录。
2. 在解压目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-desktop-plugin.ps1
```

3. 安装完成后，在 Codex 中刷新插件或新建聊天。
4. 打开 **RelayDeck 设置**，也可以在 Windows 开始菜单搜索该名称。

安装器注册的标识固定为：

- marketplace：`relaydeck-local`
- 插件：`relaydeck-desktop`
- 数据目录：`%LOCALAPPDATA%\RelayDeck`
- 设置入口：**RelayDeck 设置**

RelayDeck 只使用自己的数据目录、插件标识、证书、授权记录和计划任务。

## 首次配置

1. 在 **连接设置** 中选择一种连接方式。
2. 填写必要参数。
3. 点击 **保存并启用**。
4. 打开 **配对手机**，生成一次性二维码。
5. 在 Android App 中扫码并确认。

## 连接方式

### 局域网 / 已有网络

选择电脑当前网卡上的私有 IPv4 地址和远控端口。手机与电脑需要在同一局域网，或通过你已有的组网工具互通。

### 内置 EasyTier

填写网络名称、网络密钥、电脑虚拟 IPv4/前缀和组网节点。RelayDeck 只管理自己启动的 EasyTier 实例，不会停止系统中其他 EasyTier 进程。

### Relay

Relay 模式适合手机和电脑不在同一网络，且不希望手机常驻 VPN 的场景。

- **本机 Relay**：插件启动 `127.0.0.1:19647`，并自动生成注册密钥。
- **VPS Relay**：电脑连接 VPS 上的 `wss://` 地址，注册密钥由 VPS 配置提供。
- **frp**：把本机 Relay 或电脑网关暴露到公网时，公网入口必须是 TLS。

详见 [Relay-VPS与frp部署.md](Relay-VPS与frp部署.md)。

### 直连模式

如果已有 Tailscale、ZeroTier、frp 或其他安全隧道，可以直接填写电脑在该隧道内的地址。直连模式不导入组网参数，也不依赖 Relay。

## 手机配对

二维码包含短期配对凭据。内置 EasyTier 模式下还包含组网参数和网络密钥，只应向自己的手机展示。

配对成功后：

- 手机会获得长期设备凭据。
- 电脑端只保存设备凭据的摘要。
- 可以在设置页撤销不再使用的设备。
- 旧设备被撤销后不能继续连接。

## 会话范围

RelayDeck 同步 Codex 的交互式工作会话。Codex 里的 **Chat 引用** 会话表示某个 ChatGPT 对话被引用进 Codex 后形成的工作线程，RelayDeck 会显示这个标记，但它不是 ChatGPT 普通 Chat 的原会话。

普通 ChatGPT Chat 保存在 ChatGPT 云端，不进入 Codex 的 thread 目录，当前 app-server 也没有列出或读取这些会话消息的官方接口。因此 RelayDeck 不会通过读取令牌、抓取网页或扫描私有数据库来伪造 Chat 同步。

### Codex 本地对话

开启“允许已配对手机主动选择本机聊天”后，手机顶部的新建按钮会创建一个 RelayDeck 专用的 Codex 本地对话：

- 保存在电脑上的真实 Codex thread，支持历史、恢复、发送、流式显示、追加和停止。
- 使用当前电脑的 Codex 登录与套餐额度。
- 需要选择一个已有 Codex 工作会话作为项目目录来源，手机不能直接提交任意路径。
- 任务执行中使用“立即插话”，不提供桌面工作会话的排队队列。
- 该 thread 由 RelayDeck 独占写入；如果电脑端正在使用它，会提示冲突，不会强制抢占 writer lock。

它不是 ChatGPT 原 Chat，也不会出现在 ChatGPT 历史中。详见 [Codex本地对话.md](Codex本地对话.md)。

## 后台运行

可以在设置中开启 **保持后台运行，登录 Windows 时自动恢复**。这只会管理 RelayDeck 自己的后台任务，不会停止其他程序。

## 数据目录

```text
%LOCALAPPDATA%\RelayDeck\
  config.local.json
  manager.local.json
  manager.lock\
  relay\
    relay.local.json
    relay-devices.local.json
  chats.local.json
  secrets\
```

配置中的密钥使用 Windows DPAPI 加密。不要把 `config.local.json`、证书、Relay 注册密钥或完整配对 JSON 上传到公开位置。

## 故障排查

### 设置页打不开

- 确认插件已安装并刷新 Codex。
- 在开始菜单搜索 **RelayDeck 设置**。
- 检查 `%LOCALAPPDATA%\RelayDeck\manager.local.json` 是否指向正在运行的本机服务。
- RelayDeck 管理页面使用独立的本机端口 `127.0.0.1:29647`；该端口不会从局域网监听。
- 不要删除正在使用的数据目录；先备份。

### 手机无法连接

- 确认电脑 Codex 与 RelayDeck 后台仍在运行。
- 局域网/已有组网：确认手机能访问电脑填写的 IPv4 和端口。
- Relay：确认手机与电脑连接的是同一个 Relay，且公网地址使用 `wss://`。
- frp：确认公网入口有 TLS，路径为 `/v1/relay`。
- 检查 Windows 防火墙是否允许 RelayDeck 的本地网关端口。

### EasyTier 无法启动

- 检查网络名称、密钥、虚拟 IPv4/前缀和组网节点。
- 确认端口没有被其他程序占用。
- 创建虚拟网卡可能需要管理员权限。
- RelayDeck 不会停止你自行启动的 EasyTier 实例。

## 卸载

先撤销手机授权并停止 RelayDeck 后台，再删除插件与安装目录。数据目录 `%LOCALAPPDATA%\RelayDeck` 默认保留，确认不再需要后可手动删除。
