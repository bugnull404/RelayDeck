# RelayDeck 的 EasyTier 集成

RelayDeck 支持两种组网用法：

- **已有组网**：使用电脑已有网卡地址连接，不启动、不停止、也不重新配置已有 EasyTier 实例。
- **内置 EasyTier**：由 RelayDeck Desktop 启动并管理独立实例，Android 端通过同一套组网参数加入。

## 组件边界

Windows 内置实例使用发布包中的 EasyTier 命令行程序。RelayDeck 只管理自己启动的实例，并使用独立的设备名、管理端口和数据目录。

Android 内置组网使用固定的 ARM64 原生库，由 RelayDeck 自己实现：

- 配置解析与校验
- Android `VpnService` 生命周期
- 虚拟网卡建立
- 状态采集与错误提示

## 配置约束

- 电脑使用静态虚拟 IPv4 和子网前缀，例如 `192.168.101.1/24`。
- 手机地址由虚拟网络的 DHCP 分配，避免手工填写重复地址。
- 组网节点必须填写底层网络地址，不能填写同一虚拟子网中的地址。
- 组网名称、密钥、监听端口和管理端口由用户配置。
- 内置实例的端口不能与已有 EasyTier、网关端口冲突。
- 只应用对应虚拟子网路由，不接管默认互联网路由。

## 安全与隐私

- 组网密钥保存在 Windows DPAPI 加密配置和 Android Keystore 加密存储中。
- 完整组网状态可能包含配置密钥；RelayDeck 只持久化和展示明确选择的字段。
- 内置 EasyTier 二维码包含组网参数和密钥，只应向自己的手机展示。
- 不把配置、密钥、节点原始输出或机器路径写入日志和发布包。
- 不停止或接管用户自行启动的 EasyTier 实例。

## 构建依赖

`scripts/prepare-easytier.ps1` 会下载并校验 Android 端固定版本的原生库，构建文件位于被忽略的 `.local/native/easytier/`。桌面插件构建会下载固定版本的 Windows 程序与对应许可证。

第三方组件保留各自许可证，来源和版本记录在发布包的 `licenses/SOURCES.txt` 中。

## 真机检查

- 首次启动会显示 Android VPN 授权页面。
- 授权后能取得虚拟地址并连接电脑网关。
- 切换 Wi-Fi 与移动网络后能够恢复连接。
- 停止内置 EasyTier 后手机连接断开，但其他 EasyTier 实例不受影响。
- 错误密钥、地址冲突、端口占用和节点不可达都有明确提示。
