# 角色素材导入

RelayDeck 支持用户自行导入角色图片，用于桌面额度小部件和额度气泡。APK、源码仓库和 Release 不内置第三方角色素材。

## 使用方法

1. 打开 RelayDeck，进入 **设置 → 角色素材**。
2. 点击 **导入透明 PNG / WebP**，从系统文件选择器中选择图片。
3. 返回桌面查看已添加的 **RelayDeck 剩余额度** 小部件。
4. 点击小部件中的角色，即可弹出额度气泡。

在同一个设置页可以更换或移除素材。移除后小部件恢复默认额度卡片，额度数据和电脑配对关系不受影响。

## 图片要求

- 推荐透明背景 PNG 或 WebP，以保留角色轮廓。
- 也接受 JPEG，但 JPEG 不支持透明背景。
- 单个源文件最大 16 MB。
- 源图最大 3200 万像素。
- 导入后会缩小到最长边 1536 px，并保存为本机 App 私有目录中的 PNG。
- 图片不会上传到 Relay，不会进入配对二维码，也不会包含在 APK、源码或 GitHub Release 中。

## GPT-Niang 兼容性

RelayDeck 兼容 [GPT-Niang](https://github.com/T7moris/GPT-Niang) 的透明角色图格式，可直接从本地导入类似下面的文件：

```text
gpt-dragon-niang-bust.png
```

授权边界：

- RelayDeck **没有内置或再分发** GPT-Niang 的龙娘图片。
- GPT-Niang 的角色图片不适用该项目的 MIT 许可，只允许在原项目及其非商业副本中作为挂件或说明展示。
- 如需将角色图用于其他项目、公开发布或商业用途，应另行向素材权利人确认授权。
- 用户导入的素材由用户自行确认来源、授权和使用范围；RelayDeck 只负责在本机保存和显示。

## 隐私与清理

角色素材不参与远程同步。清除配对、更换电脑或切换 Relay 都不会删除素材；卸载 RelayDeck 会删除 App 私有目录中的素材。
